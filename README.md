# omo-mini

A planned standalone, small coding-agent CLI. This repository is an independently written project foundation, not a working CLI yet: there is no executable, installable package, or inference integration in this initial commit.

The intended implementation will use the public APIs of [Senpi](https://github.com/code-yeongyu/senpi) as a dependency. Senpi and this project share coding-agent engine heritage; omo-mini is not an official Senpi or OmO release, and no OmO plugin, prompt, or launcher code is included here.

## Status

Foundation only. CLI behavior, dependency versions, installation instructions, and tests will be added when they exist. Do not treat this repository as an executable application yet.
