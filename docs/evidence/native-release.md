# Native release observations (2026-09-24)

This is the **current independent OmO-native local profile**, not the archival v0.1 bare-Agent/read-only CLI in older evidence pages. The launcher uses pinned OmO/Senpi with project-local patches. Native read/search/edit/write/command tools, project context, permissions and JSONL sessions remain in use; this is not a cloud-workflow or OS-sandbox parity claim. The native TUI supports `/new`, `/resume`, `/local-profile` (full canonical root, selected model and loaded context), Windows **Alt+V** image paste, and active **Ctrl+C** interruption; Ctrl+V depends on terminal forwarding. `run --json` emits native JSONL events plus a nonzero `omo_mini_status` on incomplete turns. See [README](../../README.md) for usage and [licenses](../../THIRD_PARTY.md) for OmO Sustainable Use License, Senpi MIT and patch notice obligations.

On the already-loaded Qwen VLM with 69,376 loaded context, final real native ConPTY observations recorded a completed Korean model/root answer, a restored session sentinel after `/resume`, no sentinel in `/new`, one persisted multiline Unicode input, and an active Ctrl+C `aborted` turn followed by a completed recovery reply. The user separately confirmed that image paste and recognition worked. A native Windows Terminal capture and persisted session recorded an `image/png` input from the public fixture, a completed **BLUE CAT 17** answer and an idle editor. These are dated individual observations, not universal reliability guarantees. The earlier [native QA](native-qa.md) was written before TUI and clipboard acceptance and retains its original coverage gaps for that run.

Measured first outbound HTTP **request-body bytes** on one matched local task fell from 34,394 (earlier native) to 19,461 (compact native), **43.4% less**. This is neither a token-count reduction nor a general speed or accuracy claim. The first compact T07 ended without a correct dispatcher answer (explicit tool-error stop); its T12 pixel answer incorrectly called red purple/magenta. Separately, final targeted observations answered T07 correctly (active `len(events)` versus archived single delivery for nonempty input, 5 requests) and T12 correctly (top-left red, top-right blue, 1 request). T09 still ended **unfinished** at the 12-request admission limit, with an explicit error and no grounded absence answer; the historical native run had timed out after 63 requests. Local model outputs may vary. The older four-task comparison was legacy bare Agent **4/4** versus earlier native **3/4**, not a head-to-head score for this final profile.

At the final source snapshot, Windows `bun test` recorded **37 pass, 0 fail** with typecheck/build passing, and CI run [35986909381](https://github.com/asmond-lab/omo-mini/actions/runs/35986909381) recorded success on Windows and Ubuntu. These are **dated pre-publication evidence**, not a claim about a later audit, merge or installed release. Private runtime logs, screenshots and session files are not redistributed here.
