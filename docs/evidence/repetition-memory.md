# Repetition guard and native memory evidence

The native guard blocks an identical tool name and JSON arguments after that action returns an actual error. A baseline native RPC test physically executed the failing action four times where two were expected. With the guard, three identical choices in one turn yielded one physical failure and two pre-execution blocks with paired tool results. A distinct, successful command with no stdout ran; a new user turn could retry once. Three persistent blocked choices stopped the turn with a visible unfinished-work warning. Successful memory, goal, todo or read bookkeeping does not clear the failed action; only successful bash, powershell, edit or write does. The existing 12-request and five-error limits remain.

The local profile enables upstream git-backed memory and native goal/todo tools without the cloud/delegation catalog. State stays under the mini-owned state directory; memory sync and autonomous background memory workers are disabled. Run `/memfs init` in a project, use `/memfs status` or `/memory` to inspect committed memory, and intentionally use the `memory` tool to create or delete durable project facts. Resume a selected session with `/resume` to continue its current goal/todo and verified work; `/new` clears that conversation and task, not approved same-project facts. Distinct project roots get distinct identities. A bounded session-only checkpoint preserves successful native tool results with call IDs if compaction loses their context; intentions are not execution evidence.

Independent QA at the accepted implementation head: `bun test` **40 pass, 0 fail**, with typecheck and build passing. Native RPC tests covered committed create/forget, forced compaction, process restart/resume, `/new`, project isolation, failed storage visibility, and no push to a configured fake remote. A bounded loaded-Qwen run read the first public fixture, stopped with a pending next action, and read the externally created second fixture after selecting the saved session in a new process.

Limits: the real Qwen guard sample did **not** choose a duplicate; deterministic native interception is proved by the fake-provider tool-execution test. In that sample Qwen called an exit-49 command "executed successfully" despite the native error result; natural-language truth is not certified. Literal argument matching does not detect shell-equivalent commands. An automatic goal continuation immediately after a session switch can precede the durable memory marker; the observed direct user turn included the committed fact and checkpoint. No remote memory sync or arbitrary chat-to-memory promotion is enabled.
